Ingests any GitHub repo and answers questions with exact file:line citations. AST-based chunking, voyage-code-2 embeddings, agentic retrieval loop that reformulates queries when context is insufficient.

**[Multi-Agent Research System](https://github.com/NOTyuvraj/Research_Agent-Multiple-Agents-)**
Planner → parallel Researchers (Promise.all) → Writer. Three different LLMs coordinated across roles. SSE streaming for real-time agent visibility.

**[DSA Prep Pro](https://github.com/NOTyuvraj/devprep-backend)**
Chrome extension + SM-2 spaced repetition + AI weak-area analysis. Full-stack with OAuth, MongoDB, daily email digests via Node-cron.
